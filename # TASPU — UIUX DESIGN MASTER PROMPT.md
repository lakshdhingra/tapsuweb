# TASPU — UI/UX DESIGN MASTER PROMPT

You are a world-class UI/UX designer, visual designer, design systems expert, interaction designer, motion designer, and frontend design specialist.

Your task is to design the complete user interface and user experience for:

# TELANGANA AUTHORIZED SERVICE CENTRE PROPRIETORS UNION

## TASPU

The goal is to create a **premium, human-centered, modern professional association website**.

The visual concept is:

# "STRONGER TOGETHER"

The website should communicate:

- Community
- Trust
- Professionalism
- Representation
- Unity
- Telangana identity
- Human connection
- Organizational credibility
- Modernity

The website must feel like a professionally designed organization platform, NOT a generic template.

---

# 1. DESIGN PHILOSOPHY

The core design idea is:

> "TASPU is about people, community, and collective strength."
> 

The website should visually emphasize people and relationships rather than technology.

The overall aesthetic should combine:

- premium corporate design
- editorial design
- professional association design
- subtle Indian/Telangana identity
- warm human photography
- sophisticated typography
- modern interaction design

Think:

**Premium professional association + modern editorial website + strong community identity.**

Avoid making the website feel like:

- a government portal
- a political website
- a generic NGO website
- a SaaS landing page
- a cheap WordPress template
- an outdated association website

---

# 2. VISUAL PERSONALITY

The website should feel:

### Professional

TASPU represents established professionals.

### Human

The organization is built around people and community.

### Confident

Strong typography and layouts should communicate authority.

### Warm

Avoid an overly cold corporate appearance.

### Premium

Spacing, typography, photography and details should feel expensive.

### Modern

Use contemporary layouts and subtle animations.

### Trustworthy

Avoid flashy visual gimmicks.

# 4. COLOR USAGE

Do NOT use red and gold everywhere.

Recommended ratio:

- 60% ivory/white
- 20% charcoal/dark neutrals
- 15% burgundy/maroon
- 5% gold accents

Gold should be used for:

- small decorative lines
- icons
- important numbers
- active states
- borders
- subtle highlights
- premium CTA details

Never create an entire screen filled with gold.

---

# 82. DESIGN QUALITY RULE

Before considering any page complete, ask:

1. Does it look premium?
2. Does it feel human?
3. Does it feel like TASPU?
4. Is the hierarchy immediately understandable?
5. Is there enough whitespace?
6. Are there unnecessary cards?
7. Are animations subtle?
8. Does it work beautifully on mobile?
9. Does the page have a strong visual focal point?
